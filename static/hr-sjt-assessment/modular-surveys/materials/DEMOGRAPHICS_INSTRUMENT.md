# Demographics Instrument (Optional) — Modular HR SJT

Administered once per Candidate ID after consent and name/ID, before scenario ratings.
All items are optional / skippable. Stored with participant ID only (not name). Included on the PDF report.

| Item ID | Prompt | Response type |
|---------|--------|---------------|
| participant_role | Which best describes you? | Select (student / HR professional / manager / other / prefer not to say) |
| age_range | Age range | Select (18-24 … 65+ / prefer not to say) |
| gender | Gender identity | Select |
| race_ethnicity | Race / ethnicity | Multi-select (incl. Prefer not to say) |
| student_year | If student: year in school | Select |
| major | If student: major / concentration | Short text |
| years_experience | Years of professional work experience | Select |
| hr_experience_years | Years of HR-specific experience | Select |
| industry | Primary industry | Short text |
| hr_credential | HR credential (e.g., SHRM-CP, PHR) | Select |
| prior_hr_coursework | Prior formal HR coursework | Select |

Source: `modular-surveys/js/demographics.js`
