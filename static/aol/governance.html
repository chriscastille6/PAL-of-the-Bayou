1. Gap analysis (Figure 1) — holistic judgment

The diagram shows two evidence streams that feed gap judgment: course + occupational (learning objectives from syllabi, O*NET tasks and KSAOs, focal occupations, Louisiana labor context when used) and person-level evidence: direct measures (learning goals / rubrics, ETS), indirect measures (surveys, stakeholder meetings), and optional voluntary fit tools.

Other sources of evidence inform the same judgment but are not drawn as separate boxes: peer-reviewed and professional literature; practitioner / field input when PICs invite alumni, employers, or advisory partners; organizational context (resources, staffing, policy constraints); and stakeholder perspectives (students, accreditors, community partners as relevant). Committees pursue a holistic assessment: there is no single metric that perfectly quantifies whether a gap is worth acting upon — judgment, trade-offs, and governance matter.

Strategic plan (Goal 2): Holistic gap judgment and evidence streams underpin how AOL documents improvement aligned with the COB Strategic Plan (2026AY–2031AY), especially Goal 2 — committee references include Objective 2.2 (bullet 2), 2.3 (bullet 1), and 2.4 (all). See Committee agenda for the standing cross-reference.

2. Decisions A, B, and C — evidence and ownership

AOL, UPIC, and GPIC together supply the primary evidence packages for Decision A (core revision) and Decision B (program revision). Each decision type implies a revision at that scope — core, program, or course. Those are the governance-heavy moves where committees need defensible bundles.

Decision C (course revision / instructor) is likely to happen organically — good teaching and continuous improvement should not be blocked by committee process. AOL will offer suggestions instructors can use on their own (trends, gaps, cohort signals); it does not “own” or gate C.
Decision Type of change Evidence / bar (conceptual) Who leads (typical)
A — Core revision Replacing or adding core courses (largest footprint). Highest bar: e.g. course materially outdated; workforce skillset misaligned; course cannot be made current in place. PICs + Admin as policy requires.
B — Program revision Required/elective structure within a program (e.g. management, marketing). Strong program rationale; AOL / UPIC / GPIC evidence informs — not “AOL-only.” Departments / program committees.
C — Course revision Syllabus, assessments, pedagogy in a section or course. Signals for instructors; optional AOL suggestions — do not obstruct organic improvement. Instructor / chair; AOL suggests, does not mandate.

Timing (recommended order). The numbered steps below explain the sequence above in plain language. Edit this list in governance.html as your committee refines roles; keep the diagram and list aligned.

  1. AOL prioritizes analytic gaps using the agreed methodology (evidence packages).
  2. AOL → UPIC/GPIC: Forwards gaps and suggestions, with emphasis on Decisions A and B, optional tips for C.
  3. AOL → faculty: Shares faculty-facing reports and findings for review.
  4. Faculty → AOL: Returns feedback on findings and implementation feasibility.
  5. PICs → practitioners: Invite practitioner input (alumni, employers, community) when useful.
  6. Practitioners → PICs: Field relevance feedback returns to the program committees.
  7. PICs: Decide curriculum and learning goals (committee judgment).
  8. PICs → Admin: Forward recommendations that require institutional sign-off.
  9. Admin: Sign off / approve where policy requires (gate).
  10. Admin / department heads → faculty: Communicate implementation expectations.
  11. Faculty → AOL (next cycle): Syllabi and outcomes feed the next assessment cycle.
