Prerequisite diagrams (Mermaid)

Why this is here: These diagrams help steer conversations about changing curricula — prerequisites, sequencing, and knock-on effects — before anything is finalized. That visibility is especially useful for UPIC when undergraduate programs explore revisions. They complement (they do not replace) official degree requirements.

These left-to-right flowcharts match the Academic Advising tool: each box is a course; each arrow means “must complete before.” Source: Advising/templates/prerequisite_diagram.html (sibling repo under GitHub/Advising). Regenerated into aol_site/js/degree_plan_prerequisite_diagrams.js for this static demo.

Accounting (ACCT) Mermaid edges match the department’s published descriptions: ACCT 323 → 401, ACCT 322 → 403, ACCT 205 → 407 (catalog also requires 54 earned hours for 407, not drawn). Select Accounting above or open this page with ?plan=acct to view that diagram.
