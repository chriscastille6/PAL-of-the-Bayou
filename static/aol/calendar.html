Direct evidence — term checkboxes

Quick reference: The pre-2026 summary tables below are a static guide from the archived Learning Goal Assessment Timeline. For term-by-term tracking with checkboxes and localStorage, use Program learning goal assessment timelines.

Checked = direct evidence was collected in that term (rubrics, embedded exam items, ETS, etc. as applicable). Term columns: SP ’25 (Spring 2025) and SP ’26 (Spring 2026) beside Spring. The rightmost checkbox column is labeled FL ’26 as an anchor term for fall evidence on file (adjust the label in source if your evidence term differs). Unchecked = not yet in for that term (unless the cell is greyed as not-in-scope for that period — see color key below).

Defaults below reflect the latest assessed terms shared by the AOL lead; edit if your records differ. Checkboxes save in this browser only (localStorage). Your toggles override after you interact.

Term cell colors (demo): Not assessed this period / out of scope Assessed this period; evidence in Must assess this period; not yet in Assessed; data still pending committee On the BSBA timeline, SP ’26 uses committee defaults (e.g. BSAD 310 and BSAD 490 rows red; others grey). Grey cells use a disabled checkbox (not in scope for that term). Red cells are clickable; checking marks evidence collected and turns the cell green.

How often is each goal assessed? The tables below follow the college Learning Goal Assessment Timeline (Effective Spring 2014), transcribed from the scanned timeline PDF on file with the committee. In practice:

  • Each goal is assessed through specific courses; Spring and Fall columns show which terms use that vehicle for direct evidence when the course is offered.
  • If the same assessment appears under both Spring and Fall, faculty collect evidence each term the course runs (unless your department documents a different rotation).
  • Where the timeline specifies “even years only” for oral communication, only those administrations count for the oral portion; written work in the same course may still run every term—see the course rows below.
  • ETS and embedded items follow the usual offering of the listed course (e.g. capstone term).

Verify against the registrar schedule and official AOL records if anything conflicts.
