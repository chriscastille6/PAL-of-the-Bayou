Closing the loop (T1 → T2 → T3)

T1 Measure: Baseline ETS / indirect evidence identifies gaps (program level).

T2 Intervene: Curriculum, assignments, or pedagogy changes with owners and dates.

T3 Measure again: Follow-up cycle compares to T1; document results for the record.

Table 5.1 alignment (design exemplar)

AACSB Table 5.1–style documentation ties learning goals to direct and indirect measures, results, and closing-the-loop actions. The exemplar below uses a BSBA starting point adapted from publicly documented Nicholls State University Table 5-1 material to show the shape we intend to build toward. Over time, AOL will replace rows with your own programs and gap-driven content—not a static copy of any peer institution.

Source PDF (exemplar): Open Nicholls State University — Table 5.1 (PDF) — same document used to shape the default rows; opens in a new tab. In-repo copy used with permission (AOL chair).

Seven columns (Nicholls-style grid): learning goal → objectives → when/where → expected results → actual results → closing the loop → future assessment. Use the cycle control (below) to switch between the archived 2020–2024 exemplar narrative (85% targets) and the 2025–2030 COB working view (90% targets plus planned vehicles/actions from the assessment calendar, rubrics inventory, and governance / strategic crosswalk). Use the tabs for BSBA, MBA, and EMBA. Columns 1–2 stay Nicholls-exemplar wording for layout until official college text is pasted. Goal 3 expected results (ETS vs. national norm) are the same in both views.
